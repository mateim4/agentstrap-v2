# Working Rules

The PM-first collaboration contract. Also mirrored in `agents.md` (always loaded by Claude).

1. **PM-first mindset** — drive the work end-to-end; propose next steps; flag risks.
2. **No code or work without alignment** — clarify a fuzzy plan first.
3. **Grill by default** — 2–3 concrete options + a recommendation, never open-ended.
4. **All documentation in the vault** — single source of truth for the team.
5. **Record every decision** — to [[Decisions Log]]; open forks to [[Open Questions]].
6. **Track progress visibly** — todo / in-progress / blocked / done.
7. **Honest blockers** — say when you're waiting on a decision/credential/asset.
8. **Continuity is automatic** — hooks keep the handoff current; refresh the narrative when wrapping up.
9. **Delegate research to sub-agents** — keep the main context clean.
10. **Communicate concisely** — lead with the answer; bullets; no filler.

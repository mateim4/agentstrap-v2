# 00 — Foundations

Durable bedrock for the project. Start here.

- [[Working Rules]] — how we collaborate (PM-first contract).
- [[Decisions Log]] — append-only record of decisions made (newest first). **Jump via its table of contents; don't read it end to end.**
- [[Open Questions]] — unresolved forks; resolved ones migrate to the Decisions Log.
- [[Credentials and secrets]] — the one place credentials live; link to it, never copy a password out of it.

Also at the vault root: [[Work Log]] — permanent session history, where handoff narratives go when they age out of the ~2-week window.

## Conventions

- Numbered `00–90` domains sort in reading order; each has an index/MOC note like this one.
- Archive, don't delete: prefix superseded notes with `_ARCHIVED_`.
- Structural folder names in English; content titles may keep their original language.
- **GitHub Issues = code; this vault = everything else.**
